# 🚗 Workshop Management System

A Spring Boot web application connected to a MySQL database that manages workshop customers, vehicles, and repairs.  
This project demonstrates CRUD operations, database integration, and Thymeleaf front-end rendering.

---

## 📌 Features

- Display list of customers from MySQL database
- Spring Boot MVC architecture
- Thymeleaf HTML templating
- MySQL database integration via Spring Data JPA
- Auto schema update using Hibernate
- Simple workshop dashboard view

---

## 🛠️ Tech Stack

- Java 17+
- Spring Boot
- Spring Data JPA
- MySQL
- Thymeleaf
- HTML & CSS

---

## 🗄️ Database Structure

The project uses a MySQL database named:


workshop_db


### Tables:
- customer
- vehicles
- repairs

(See `/database/schema.sql` for full SQL setup)
